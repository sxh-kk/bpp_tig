# Archived v1 Python source

These Python files are exact bytes of the frozen baseline used for `metrics/v1_clip1`. They retain the documented quantile/DDIM support mismatch and omit native EMA/input perturbation. They are historical, not the corrected default. Source SHA256 values are in `provenance.json`.

The baseline expects installation at `The-Imitator-Game/examples/baselines/bpp`. For a separate v1 reproduction checkout, overlay this archived Python tree there; do not run its entrypoints directly from this nested archive, and do not overwrite a running v2 installation. Data, robot assets, raw rollout logs/videos and trained checkpoints are not included in this repository.
